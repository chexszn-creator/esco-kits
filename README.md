# esco-kits

Static product site for AutoFlow Digital (plain HTML/CSS, no build step needed to serve).
Generated by `/workspace/site/src/build.py`. Rebuild with the real Pages URL:

    BASE_URL=https://<user>.github.io/esco-kits python3 /workspace/site/src/build.py

Thank-you/download pages: `/thank-you/<kit-slug>/` (noindex). Point each Stripe Payment Link's
after-payment redirect to its thank-you URL.
