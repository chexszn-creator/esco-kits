## 1) Morning ritual (5 minutes)
1. Open yesterday’s numbers (phone, booking app, or paper).
2. Fill **one row** on the daily scorecard.
3. Circle anything yellow/red.
4. Pick **one** fix for today (not five).
5. Text the office/lead tech the one fix.

Rule: *What gets scored daily gets fixed weekly.*

## 5) Bottleneck cheat sheet
| Red metric | Likely cause | First fix (today) |
|------------|--------------|-------------------|
| High missed % | No after-hours path / phones on truck only | Forward to SMS-capable line; use Missed-Call Rescue Kit scripts |
| Slow text-back | Nobody owns the phone | Assign one person 8a–6p; template ready |
| Low book rate | Weak script / no 2-window offer | Use 30-sec booking callback; offer two times |
| Low cash collected | Invoice lag / “bill later” habit | Collect card on booking or before tech leaves |
| Few review asks | Techs forget | Tech asks at door + office SMS ask same day |
| Callbacks piled up | No owner end-of-day sweep | 10-min closeout: clear all callbacks before dinner |
| Truck delays | Overbook / parts / bad map order | Cap same-day adds; stage parts night before |

---

## 6) 30-day owner targets
- Missed-call rate **under 20%**
- Text-back on missed **≥80% within 60 seconds**
- At least **1 review ask per completed job** (or honest attempt)
- Overnight callbacks **≤1**
- One written “week leak” every Friday
