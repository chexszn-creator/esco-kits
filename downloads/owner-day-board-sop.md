## 2) End-of-day closeout checklist

Do this in ≤10 minutes. Same order every night.

### Phones & leads
- [ ] Missed-call log reviewed (who texted back / who still open)
- [ ] Tomorrow’s first two slots protected for emergencies if season is hot/cold
- [ ] After-hours path confirmed (who answers / who gets SMS)

### Jobs & money
- [ ] All completed jobs marked done in the board / software
- [ ] Invoices sent or cash logged
- [ ] Open quotes listed with next follow-up date
- [ ] Parts used vs truck stock noted for restock

### People
- [ ] Each tech’s last job closed or handed off
- [ ] Any angry customer / callback flagged for morning
- [ ] On-call tech confirmed for tonight

### Reviews & reputation
- [ ] Ask-for-review SMS sent on clean, paid jobs (optional pack: Review Reply Pack)
- [ ] Any new 1★ / 3★ seen → owner/manager owns reply

- [ ] Day-board skeleton started (jobs + techs)

## 3) Hiring phone-screen script (1–2 pages)

**Use for:** tech or office applicants. **Time:** 10–12 minutes. **Goal:** decide “invite to in-person” vs “pass” — not hire on the phone.

### Before you dial
- Role: Tech / Apprentice / Office  
- Must-haves (circle): driver’s license · own tools · EPA · experience years ___ · nights/weekends OK  
- Pay range you’ll actually say: $________ – $________

### Open (30 sec)
“Hey {{name}}, this is {{you}} with {{shop}}. Thanks for applying — I’ve got about ten minutes to see if we’re a fit either way. Sound good?”

### Basics (2 min)
1. “Where are you commuting from, and is that doable for a {{start_time}} start?”
2. “Are you legally able to work in the US, and do you have a valid driver’s license?”
3. “Any schedule limits we should know — kids, second job, school?”

### Experience (4 min)
4. “Walk me through the last similar role — what did a normal day look like?”
5. “What kinds of calls are you solid on? What’s still stretch?”
6. “Tell me about a callback or angry customer — what did you do?”
7. “Tools / certifications you already have?” (note EPA, brand training, CRM)

### Work style (2 min)
8. “We run a day board: jobs, emergencies, callbacks. How do you like getting dispatched?”
9. “Ever texted a customer you missed? Comfortable with that?”
10. “What would make you leave a shop in the first 90 days?”

### Logistics (1–2 min)
11. “Pay you’re targeting?” (don’t negotiate hard yet — listen)
12. “How soon could you start?”
13. “OK if we do a background / driving record check if we move forward?”

### Close
**If promising:** “I’d like you to come in / ride along on {{day}}. We’ll show the trucks and the board. Questions for me?”  
**If not:** “Appreciate your time — I don’t think we’re the right match right now. Best of luck.”

### Score (circle)
| Signal | Weak | OK | Strong |
| --- | --- | --- | --- |
| Reliability / commute | 1 | 2 | 3 |
| Skill match | 1 | 2 | 3 |
| Customer temperament | 1 | 2 | 3 |
| Fit with small-shop chaos | 1 | 2 | 3 |

**Invite if:** mostly 2–3s and must-haves clear. **Pass if:** red flags on license, honesty, or “I don’t do callbacks.”

- [ ] Offer / rate / schedule confirmed in writing
- [ ] W-4 / I-9 / direct deposit started

### Day 1
- [ ] Tour shop, trucks, parts, safety gear

- [ ] Phone / SMS scripts overview (missed-call + review ask if you use them)
- [ ] Shadow one call or one office block
- [ ] End-of-day: what went well / what’s confusing (5 min)

### Days 2–3
- [ ] Second shadow or light solo with check-ins
- [ ] Parts tagging / invoice habit shown once
- [ ] Introduce to each tech / office person by name
- [ ] Review “who owns what” (section 5)

### Days 4–5
- [ ] First owned job or owned phone block with backup nearby
- [ ] Callback protocol practiced
- [ ] Safety / ladder / refrigerant / lockout as relevant
- [ ] Friday: 15-min check-in — keep / coach / concerns

### End of week 1 (owner)
- [ ] Written note: strengths, one coaching item, week-2 plan
- [ ] Confirm they know on-call / overtime expectations
- [ ] Schedule week-2 ride-along or CSR audit

## 5) Who owns what (RACI-lite)

R = Responsible (does it) · A = Accountable (final call) · C = Consulted · I = Informed

| Work item | Owner | Office | Tech |
| --- | --- | --- | --- |
| Morning day-board final | A | R | I |
| Dispatch changes midday | A/C | R | C |
| Emergency accept / decline | A | C | R (on site) |
| Callbacks / warranty | A | C | R |
| Invoicing / collections | A | R | C (job notes) |
| Parts restock | C | R | C (truck list) |
| Hiring decision | A | C | I |
| Review replies (≤4★) | A/R | C (draft) | I |
| After-hours phone path | A | R/C | R (on-call) |
| Truck maintenance flag | I | C | R |

**Conflict rule:** If Owner and Office disagree on a same-day emergency, Owner decides once — then update the board so Tech isn’t guessing.

## 6) Weekly ops review (30 minutes)

**When:** same slot each week (e.g. Monday 7:30a or Friday 4:30p)  
**Who:** Owner + office lead (techs optional for last 5 min)

### Agenda
| Min | Topic | Prompt |
| --- | --- | --- |
| 0–5 | Numbers | Jobs completed, emergencies, callbacks, cash collected, missed calls |
| 5–12 | Board pain | Where did the day board break? Late parts? Overbook? |
| 12–18 | People | Attendance, coaching, hiring pipeline |
| 18–24 | Customers | Angry calls, reviews, promises due |
| 24–30 | One change | Pick **one** process fix for next week — write it |

### Capture sheet
- Wins: ________________________________
- Problems: ________________________________
- One change next week: ________________________________
- Owner owns: _____________ Office owns: _____________

**Rule:** No more than one big process change per week. Finish last week’s change before stacking another.
