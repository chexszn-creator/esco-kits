Dispatch board template for small HVAC and plumbing shops

Updated 2026-09-30 · AutoFlow Digital. Swap the {placeholders} for your own details.

You don't need expensive field-service software to run a clear day. A small shop can run well on one board (whiteboard, spreadsheet or Notion page) if everyone uses the same columns.

Section A: jobs on the board

Time window | Address / zone | Job type | Tech | Priority (N/E/C) | Parts / notes
8–10a       |                |          |      |                  |
10–12p      |                |          |      |                  |
12–2p       |                |          |      |                  |
2–4p        |                |          |      |                  |

N = normal · E = emergency · C = callback/warranty

Section B: tech roster

Tech | Truck stocked? | First stop | Capacity left? | On call tonight?

Section C: waiting list

Customers who want the first opening. When a job cancels, you call this list first instead of leaving the slot empty.

How to run it

  1. Fill it the evening before and adjust in the morning.
  2. Group jobs by zone to cut drive time.
  3. Leave one flex slot a day for emergencies if your volume allows.
  4. Mark callbacks clearly, since they show you where quality needs work.

End of day

Every job gets marked done, rescheduled or needs-return. Anything not marked is a question someone has to answer tomorrow.
